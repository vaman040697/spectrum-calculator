Equation solver

Write an equation with =. The solver searches the chosen interval numerically and reports real roots it can find.

Try x^2 = 4 or sin(x) = 0.

Numerical, not symbolic

This gives real approximations for many classroom-sized equations. Exact factorisation, complex roots, systems, and assumptions belong in the deeper CAS phase.

If the function has a discontinuity or a very narrow root, widen the interval or use a graph to inspect it first.

CAS / symbolic algebra starter

Differentiate, integrate, or normalize common polynomial and trigonometric expressions. For example: 3*x^3 - 2*x + sin(x).

Scope

This is a useful learning layer, not yet a full computer algebra system. A deeper version should add a proper symbolic engine for factoring, solving, limits, matrices, assumptions, and exact arithmetic.

The answer stays symbolic; no server is needed for these starter rules.

Python scratchpad

Code runs in a separate worker so the calculator remains responsive. Stop resets the runtime and variables. Each run has a 30-second limit after loading.

The first load needs an internet connection. Core Python is included; extra packages are not automatically installed. Only run code you trust. This is a single-script scratchpad, not a multi-cell notebook.
